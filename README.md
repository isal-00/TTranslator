# TTranslator

Um tradutor desenvolvido com HTML, CSS e JavaScript, com o objetivo de praticar e aplicar conceitos de desenvolvimento web.

## Sobre o projeto

O TTranslator é um projeto desenvolvido para estudos e prática de desenvolvimento web.

O projeto também foi pensado para receber novas funcionalidades ao longo do desenvolvimento.

## Funcionalidades

- Tradução de textos
- Seleção de idioma
- Interface responsiva
- Captura de voz pelo microfone
- Reprodução da tradução em voz alta (em desenvolvimento)
- Interface simples e intuitiva

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API de tradução
- Git
- GitHub

## Status

**Em desenvolvimento**

Novas funcionalidades e melhorias serão adicionadas ao projeto conforme o seu desenvolvimento.

## Objetivo

Esse projeto faz parte do meu processo de aprendizado em desenvolvimento web, com foco em HTML, CSS, JavaScript, consumo de APIs e controle de versão utilizando Git e GitHub.
